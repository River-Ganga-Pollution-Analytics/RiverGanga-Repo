# 02 — Data Collection

This folder stores the datasets and documentation used in the River Ganga water-quality analysis.

## Expected contents
- Original/raw dataset files (CSV or Excel)
- Dataset source and attribution details
- Data dictionary describing columns and units
- Notes about collection period, locations, and limitations

## Data integrity
Keep an unchanged copy of each original dataset. Do not overwrite raw data during cleaning. Clearly label sample, simulated, or synthetic data; do not present it as official real-time monitoring data.
